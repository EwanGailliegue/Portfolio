Projet principal SAÉ 6

Jardins de Cocagne

Application mobile de gestion des livraisons de paniers biologiques

Cross-platform

Développement de deux applications mobiles complémentaires (livreur & client) pour les Jardins de Cocagne, une structure distribuant des paniers biologiques en circuit court. Le projet couvre l'ensemble du cycle : conception, développement Flutter, API REST Node.js, base PostgreSQL, et déploiement avec notifications push Firebase.

App Livreur

  • Authentification JWT avec stockage sécurisé (Keychain / Keystore)
  • Affichage des tournées du jour et récapitulatif des paniers
  • Scan QR code du dépôt et de chaque panier individuel
  • Mise à jour instantanée du statut côté serveur
  • Carte interactive OpenStreetMap avec marqueurs colorés par état
  • Navigation GPS vers le dépôt suivant via url_launcher

App Client

  • Tableau de bord avec statut de la prochaine livraison
  • Historique complet des livraisons et détail des paniers
  • Notifications push Firebase reçues dès la validation du panier
  • Fonctionne en arrière-plan et application fermée (FCM)
  • Marquage des notifications comme lues

Les clients reçoivent une notification push dès que le livreur valide leur panier. Fonctionne même si l'app est fermée grâce à Firebase Cloud Messaging (FCM).

Implémentation

  • Enregistrement du token FCM au démarrage de l'app
  • Listener onTokenRefresh pour mise à jour automatique
  • Handler background isolé pour les notifications en arrière-plan
  • Envoi depuis le backend via Firebase Admin SDK
  • Nettoyage automatique des tokens FCM expirés

API REST complète avec authentification JWT, gestion des rôles et routes dédiées livreur / client / admin. Connectée à une base PostgreSQL (schéma cocagne).

Routes principales

  • POST /auth/login · GET /auth/me
  • GET /deliverer/runs/today · /runs/:id/stops
  • POST /deliverer/scan/depot · /scan/package
  • GET /client/dashboard · /deliveries · /notifications
  • POST /client/push-token · /notifications/mark-read
